#Introduction

[NPM (Node Package Manager)](https://pauloe-me.medium.com/typescript-npm-package-publishing-a-beginners-guide-40b95908e69c) is the default package manager for the JS/TS programming language. It allows developers to easily install, manage, and share reusable JS/TS code packages, also known as modules or packages.


**Use of NPM Package in CPF**

- We will store important and common utilities( Eg. Send Message to service bus utility) that can be used across multiple test automation projects.
- There will be incremental release of the NPM package for usage.
- User needs to install the latest version of the npm package to get the latest version of the utilities.


----------------------------------------------------------------------
**Prerequisite** 

Update the PAT token in the **.npmrc** file.
Below are the steps to update the PAT Token:
-  Navigate to [User Settings -> Security -> Personal Access Tokens](https://crowevs.visualstudio.com/_usersSettings/tokens) and Generate the Token. For more information please refer to [how to create PAT?](https://learn.microsoft.com/en-us/azure/devops/organizations/accounts/use-personal-access-tokens-to-authenticate?view=azure-devops&tabs=Windows#create-a-pat)

-  Base64 encode the personal access token
       
   - From a command/shell prompt run:
     **`node -e "require('readline') .createInterface({input:process.stdin,output:process.stdout,historySize:0}) .question('PAT> ',p => { b64=Buffer.from(p.trim()).toString('base64');console.log(b64);process.exit(); })"`**

   - Paste your personal access token value and press Enter/Return
   - Copy the Base64 encoded value  



      ![image.png](/.attachments/image-17accd9d-bbde-4fb0-96a8-6fd53940f037.png)

-  Replace both [BASE64_ENCODED_PERSONAL_ACCESS_TOKEN] values in your user .npmrc file with your personal access token

**Install CPF Utilities Package**
  - Navigate to the project directory and open cmd or gitbash.
  - Run the command `npm install` with the desired version of the package (example: `npm install playwrightutilities@1.0.0`). For version details, please refer to [Release Notes](/Release-Notes)
  - Verify the package is added to node modules and dependency is added to package.json.
