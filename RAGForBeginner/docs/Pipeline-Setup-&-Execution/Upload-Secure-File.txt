
# Introduction
Secure files give you a way to store files that you can share across pipelines. The contents of the secure files are encrypted and can only be used when you consume them from a task. Secure files are a protected resource. You can add approvals and checks to them and set pipeline permissions

# Add Secure file & Provide Permission to Pipeline
Upload the environment files in the library section using the secure file option and provide pipeline permission to every secure file uploaded.

# Consume a secure file in Azure Pipeline
Use the Download Secure File utility task to consume secure files in a pipeline. This task will download the secured environment file into the build directory and will be utilized for test execution.
